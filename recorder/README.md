# X3 Recorder

Запись экрана + звук на Android, на чистом Java (без Gradle).

## Как работает

1. Приложение запрашивает разрешение **«Отображение поверх других приложений»**.
2. После «Запустить» на экране появляется **красная точка со временем** записи.
   - Тап по точке — панель управления.
   - Перетаскивание точки — сдвиг по экрану.
3. Панель:
   - **Записать** — запись экрана (MediaProjection) + звук.
   - **Режим звонка: вкл/выкл** — вместо микрофона использовать источник `VOICE_CALL`
     (записывается звук звонка со всего телефона, а не только микрофон).
     Работает там, где система разрешает `VOICE_CALL`; на части устройств
     (например, Pixel на новых Android) система отдаёт микрофон — это ограничение Android,
     без root полного доступа к внутреннему звуку нет.
   - **Пауза** — останавливает запись на время, **Продолжить** — включает заново (тот же файл,
     пауза просто не попадает в видео).
   - **Стоп** — завершить и сохранить.
4. Уведомление фона с текущим временем и кнопкой «Стоп».

Видео сохраняется в:
- Android 10+ → `Movies/X3` (через MediaStore)
- Android 7–9 → `Movies` (нужно разрешение на запись в память)

## Формат

MP4 (H.264 + AAC), до 1920px по длинной стороне, 30 fps, 8 Мбит/с.

## Файлы

```
AndroidManifest.xml          манифест (com.x3.screenrec, minSdk 24, targetSdk 34)
build.sh                     локальная сборка aapt + javac + d8 (нужен $ANDROID_HOME)
res/                         layout, строки, иконки
java/com/x3/screenrec/
    MainActivity.java        экран старта: разрешения + запуск
    ProjectionBridgeActivity.java  системный диалог согласия на запись экрана
    RecorderService.java     точка-оверлей + MediaProjection + MediaRecorder
```

## Сборка

- **CI**: `.github/workflows/build-recorder.yml` → артефакт `X3Recorder-APK`
  (подпись тем же P12 из секретов `CB4_P12_BASE64`/`CB4_P12_PASSWORD`, что и игра).
- **Локально**: `./build.sh` (нужны `platforms;android-34`, `build-tools;34.0.0`, JDK 11+),
  затем подписать `apksigner`.
